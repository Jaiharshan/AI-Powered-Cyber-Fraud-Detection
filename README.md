# 🛡️ AI-Powered Cyber Fraud Detection

An intelligent cybersecurity platform for detecting phishing attempts, fraudulent messages, malicious URLs, and suspicious communications using machine learning and automated incident response workflows.

## 🚀 Features

- Real-time fraud detection
- URL risk analysis
- Email phishing detection
- Automated incident escalation
- Priority-based incident management (P1–P4)
- Batch CSV/TXT scanning
- Export incidents as CSV or JSON

## 🛠️ Tech Stack

- Python
- Streamlit
- Scikit-learn
- Pandas
- NumPy
